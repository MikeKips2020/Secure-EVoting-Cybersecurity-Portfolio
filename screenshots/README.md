# Security Testing and System Demonstration Screenshots

This folder contains selected screenshots from my MSc Secure Electronic Voting System cybersecurity project.

The screenshots demonstrate:

1. Security audit logging and monitoring.
2. Ballot integrity verification.
3. Administrative access control.
4. Security testing and validation.
5. System functionality and deployment.

All screenshots are provided for academic and professional portfolio demonstration purposes.

Sensitive information, personal data, credentials and confidential system details are excluded or redacted.

The application is an academic research prototype and is not intended for use in real elections.
